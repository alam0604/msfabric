## Suggested study plan (2 weeks)
1. **Days 1–3:** 01-theory + Microsoft Learn overview & lakehouse tutorial.
2. **Days 4–6:** 02-important-topics (tables + code), do the hands-on labs.
3. **Day 7:** 03-fabric-vs-azure-synapse.
4. **Days 8–11:** 04 theory questions — answer aloud without looking.
5. **Days 12–14:** 04 scenario questions — sketch the architecture for each.

> Fabric changes monthly — check the Fabric blog's "What's new" before an interview.
